How it works

// field initializer = injection context
private reportService = injectAsync(() =>
  import('../services/cart-report.service').then(m => m.CartReportService)
);

async generateReport() {
  const service = await this.reportService(); // chunk loads HERE (once)
  this.report.set(await service.generateCatalogReport());
}

// optional: download the chunk while the browser is idle
injectAsync(loader, { prefetch: onIdle });
  • The lazily injected service must be auto-provided (providedIn: 'root' or @Service())
  • injectAsync must run in an injection context — fields and constructors, not event handlers
  • Repeated calls return the same instance; the network cost is paid once
